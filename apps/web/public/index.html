Install

One command installs locus and locus-mcp. At the v0.6.2 release the Homebrew tap installs v0.6.1, so use npm for v0.6.2. The v0.6.2 npm wrappers fail closed if a release checksum sidecar is missing, unparseable, unreachable, or mismatched, and a checksum failure does not fall back to Cargo. Checksums detect corruption, not publisher authenticity. Source installs need Rust 1.89 or newer.

both binaries
npm install -g locus-cli @ashlrai/locus-mcp
tap is v0.6.1 at the v0.6.2 release
brew install ashlrai/tap/locus
Rust 1.89 or newer
cargo install --git https://github.com/ashlrai/locus locus-cli --locked

Read JSON

Run this in one shell. LOCUS_HOME keeps the trial off your real home directory. The first JSON key is schema. Nothing here prints a secret. --expect acme exits 1 with pin_mismatch and does not start the child.

throwaway home
export LOCUS_HOME="$(mktemp -d)"
locus quickstart
eval "$(locus hook bash)"
locus enter personal
locus whoami --json
locus status --json
locus doctor --json

MCP for Claude, Cursor, and Codex

Provider tools need locus mcp --supervised, a live pin, and the control capability in the shell that launches the client. Restart the client after a re-pin. Agents cannot pin. locus setup --client claude --print prints the control-tools entry and writes nothing.

.mcp.json
{ "mcpServers": { "locus": { "command": "locus", "args": ["mcp", "--supervised"] } } }
~/.cursor/mcp.json
{ "mcpServers": { "locus": { "command": "locus", "args": ["mcp", "--supervised"] } } }
~/.codex/config.toml
[mcp_servers.locus]
command = "locus"
args = ["mcp", "--supervised"]

How it works

01

A person pins

locus enter acme seals the session to one binding. An agent can ask with locus_request_pin. It cannot pin.

02

The seal is checked

An HMAC seal plus a live broker. A bad seal, an unknown binding, or a scope mismatch is a deny.

03

Tools follow the pin

The MCP catalog is this pin only. locus exec scrubs ambient GH_TOKEN, AWS_*, SUPABASE_*, and VERCEL_*.

FAQ

Can an agent change the pin?

No. Pin changes are human commands: locus enter, locus pin, locus switch. If the tools are the wrong tenant, ask a person to pin.

Where do secrets go?

Bindings store env:VAR and phm:NAME pointers, never raw tokens. MCP results do not return resolved values. phm: resolution fails closed until a scoped bridge exists.

Is Locus a sandbox?

No. It scrubs the child environment and redirects HOME. A process can still open a file by an absolute path the operating system already allows.

What does the json flag print?

One JSON object whose first key is schema, such as locus.whoami.v1. Failures use locus.error.v1. The field list is locus topic agent-contract --json.
