Use case · CI and remote agents

A sealed identity
for the runner.

CI jobs usually inherit a shared PAT and every ambient variable on the runner. Locus mints short-lived sealed sessions scoped to one binding, and serves MCP over a token-authed loopback HTTP transport.

HTTP transport doc → Install
What you get

  • Ephemeral pins. locus ci mint|env|run mints short-lived sealed sessions for CI, sharing the same store and seal as interactive pins.

    docs/architecture.mddocs/mcp.md

  • Token-authed HTTP MCP. locus-mcp --http binds loopback and requires Authorization: Bearer <LOCUS_MCP_HTTP_TOKEN> (or X-Locus-Token / X-Locus-Mcp-Token); a raw schemeless token is rejected.

    docs/mcp.md · HTTP transport

  • Fail-closed pre-auth limits. Declared Content-Length above 8 MB → 413; request line + headers above 32 KB or more than 128 header fields → 431; unparseable JSON-RPC → 400 with -32700. Checks run before any body allocation.

    docs/mcp.md · HTTP transport

  • Session ids that can't be exhausted. Mcp-Session-Id is minted on initialize only; other POSTs without one are served statelessly, so garbage POSTs cannot exhaust session capacity.

    docs/mcp.md · HTTP transport

  • Diagnostics can't leak secrets. exec / run / ci run with --no-resolve cannot resolve provider credentials or spawn credential-resolving workers, and fail before child or credential effects if a recipe expands to resolve_secrets = true.

    docs/mcp.mddocs/adapters.md

  • Pin mismatch exits 1. In the repo benchmark, locus exec --expect acme while personal was pinned exited 1 with pin_mismatch and ran nothing.

    docs/BENCHMARKS.md

  • Signed credential audit. An opt-in audit keeps a signed, value-free record of every credential injected into a child environment; with nothing configured, nothing extra is read or written.

    docs/credential-audit.md

  • Fast enough for per-job pins. The repo's measured median for locus exec -- true is 0.004 s on the benchmark machine, so a fresh pin per job costs milliseconds.

    docs/exec-latency.md
The shape
ci · ephemeral pin 
export LOCUS_MCP_HTTP_TOKEN="$(openssl rand -hex 16)"
locus ci mint --binding acme-ro --ttl 30m  # ephemeral sealed session
locus-mcp --http          # 127.0.0.1:8742 · Bearer auth
locus exec --expect acme-ro -- ./deploy.sh
# wrong pin → pin_mismatch, exit 1, nothing ran
