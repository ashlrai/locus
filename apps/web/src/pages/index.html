Install
# release binaries into ~/.cargo/bin
export PATH="$HOME/.cargo/bin:$PATH"
cargo install --git https://github.com/ashlrai/locus \
  locus-cli locus-mcp --locked

# or from a local checkout
cargo install --path crates/locus-cli
cargo install --path crates/locus-mcp
# downloads a release binary (falls back to cargo)
npx locus-cli --help
npx locus-mcp  # MCP server for Claude Code / Cursor
# when the tap is published
brew install ashlrai/tap/locus

Architecture
locus enter acme │ ▼ Session sealed (HMAC) → binding "acme" │ ├─► locus-mcp tools = this binding only (+ locus_whoami) │ agents cannot pin · freeze · resources/prompts │ ├─► dashboard serve · whoami · doctor · approvals (127.0.0.1) │ └─► locus exec scrub ambient · resolve phm:/env: · private worker dirs
How it works
01

Bind tenant × providers × policy

A binding is principal, tenant, credential refs, and freeze scopes, never raw secrets.

docs/firm-mode.md
02

Human pins. Agents cannot.

locus enter acme seals the session. MCP only offers locus_request_pin.

AGENTS.md · invariants
03

Catalog is the isolation boundary

Unpinned → control tools only. Pinned → that client's provider tools. Nothing ambient leaks in.
