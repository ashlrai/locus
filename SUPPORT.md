# Getting Help with Locus

Locus pins each coding-agent session to one Binding, so wrong-account action is blocked at the gate. This page says where to take a question, bug, or report.

## Start here

- **Install and first run:** [README.md](./README.md#30-second-start) and [docs/copy-paste.md](./docs/copy-paste.md) (runnable command blocks).
- **Wiring an MCP client** (Claude Code, Cursor, Codex, Gemini CLI, Grok Build): [docs/mcp.md](./docs/mcp.md).
- **`--json` output, exit codes, dry-run:** [docs/agent-contract.md](./docs/agent-contract.md).
- **Policy rules and approvals:** [docs/policy.md](./docs/policy.md).
- **Onboarding multiple clients and tenants:** [docs/onboarding.md](./docs/onboarding.md).
- **Doc index:** [docs/README.md](./docs/README.md).
- **Coding agents:** [llms.txt](./llms.txt) is the agent index, and [AGENTS.md](./AGENTS.md) holds the rules agents follow in this repository.

## Questions and bugs

- **Bug reports:** open an issue with the [bug report form](https://github.com/ashlrai/locus/issues/new?template=bug_report.yml). Include the Locus version, platform, the command you ran, and the output with secrets removed.
- **Feature requests:** use the [feature request form](https://github.com/ashlrai/locus/issues/new?template=feature_request.yml).
- **Open questions:** search existing [issues](https://github.com/ashlrai/locus/issues) first. Unanswered questions are welcome as new issues.

Never paste credentials, `phm:` or `env:` values, seal material, or `~/.locus` contents into an issue, a pull request, or a discussion. Redact them first.

## Security problems

Do not open a public issue for a security problem. Report it privately as described in [SECURITY.md](./SECURITY.md).
